# Charte télétravail (exemple fictif)

Le télétravail est possible jusqu'à 3 jours par semaine après la période d'essai.

Une indemnité forfaitaire de 2,70 euros par jour télétravaillé est versée chaque mois avec le salaire, dans la limite de 59,40 euros par mois.

Le salarié doit disposer d'une connexion internet stable et respecter les règles de sécurité informatique : VPN obligatoire, pas de données client sur un poste personnel.
